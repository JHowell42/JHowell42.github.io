Infinite Dungeon - Text-Based RPG

Infinite Dungeon is a fully interactive text‑based RPG built in C++. Players explore a procedurally generated dungeon, battle enemies, collect items, choose character classes, and progress through increasingly difficult floors. The game features a complete combat system, class abilities, elite and rare enemy variants, and a polished console interface.

Key Features

  • Turn‑based combat system with class abilities.
  • Dungeon exploration with multiple room types.
  • Inventory system with consumables and equipment .

What I Learned

One major challenge was managing the complexity of a multi‑file C++ project as new systems were added. I encountered constructor mismatches, linker errors, and type conversion issues while expanding the game. By reorganizing my code, debugging step‑by‑step, and using GitHub issues to plan features, I learned how to structure large projects and maintain clean, modular code.
